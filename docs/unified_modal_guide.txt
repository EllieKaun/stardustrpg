Формат как у прошлых гайдов, но кода больше: ядро системы дано целиком, его
можно вставлять как есть. Делай по частям, после каждой проверяй в игре.
Номера строк — по ветке feature/ai-enemy-decision.

Сейчас в игре семь окон, и каждое написано отдельно:
  1) диалоги с персонажами и сундуки   — объект oDialogManager
  2) обучение                           — TutorialRunner (scrTutorial)
  3) «Новая карта»                      — объект oCardReward
  4) «Инфо» в бою                       — состояние боя EnemyInfoDisplay
  5) подтверждение побега               — состояние боя RunConfirm
  6) выбор карты при победе             — состояние боя Victory (scrGameOver)
  7) поражение                          — состояние боя GameOver (scrGameOver)

Что получится:
  - один объект oModal со стеком окон: верхнее получает ввод, рисуются все;
  - окно описывается ДАННЫМИ (структура spec), а не отдельным кодом;
  - содержимое окна собирается из блоков: заголовок, текст, кнопки, карта,
    выбор карт, портрет, строки статистики, своя отрисовка и т.д.;
  - семь окон становятся шестью функциями-«пресетами» (диалог и сундук — один
    пресет, побег и поражение — один пресет «подтверждение»);
  - любое окно можно поменять при вызове, не трогая пресет: modalOpen(пресет, {
    что поменять });
  - новые виды блоков и окон добавляются одной записью, как эффекты в
    initEffectRegistry.

================================================================================
  ЧАСТЬ 0. ПРИНЯТЫЕ РЕШЕНИЯ
================================================================================

0.1. Один менеджер, стек окон.
  Объект oModal создаётся сам при первом вызове modalOpen и живёт всю игру
  (persistent). В нём массив окон. Ввод получает только верхнее окно, рисуются
  все снизу вверх. Окно поверх окна (подтверждение поверх диалога) работает
  само собой.

0.2. Окно — это данные.
  modalSpec({...}) возвращает структуру с умолчаниями, в которой можно
  переопределить любое поле. Страница (page) может переопределить любое поле
  окна: например, одна реплика диалога с другим размером рамки.

0.3. Содержимое — блоки из реестра.
  Как эффекты в initEffectRegistry: global.modalBlocks[$ вид] = { draw: ... }.
  Новый вид блока = одна запись в реестре + функция-конструктор.

0.4. Старые точки входа не меняются.
  say(lines, onComplete), dialogLine, dialogChoice, showCardReward — остаются с
  теми же параметрами, но внутри открывают новое окно. Квесты, сундуки, Фира,
  Сафар не трогаем вообще.

0.5. В бою логика остаётся в машине состояний.
  Состояния RunConfirm, EnemyInfoDisplay, Victory, GameOver остаются: бой
  по-прежнему знает, где он. Меняется только интерфейс: при входе в состояние
  открывается окно, кнопки окна переключают состояние. Свои Step/DrawOver у
  этих состояний уходят.

0.6. global.uiModal ведёт менеджер.
  При открытии первого окна запоминается прежнее значение, после закрытия
  последнего — возвращается, причём только в начале СЛЕДУЮЩЕГО кадра. Это
  заодно убирает «сквозной клик» (часть 4).

0.7. Переезжаем по одному окну.
  Старое и новое живут вместе, пока переезд не закончен. После каждого окна
  игра работает.

0.8. Пауза, декбилдер, магазин и альбом — не в этой задаче.
  Это полноэкранные меню со своими панелями, а не модальные окна. Позже их тоже
  можно перевести, но это отдельная работа.

================================================================================
  ЧАСТЬ 2. МОДЕЛЬ: ОКНО = РАМКА + СТРАНИЦЫ + БЛОКИ
================================================================================

    spec (окно)
    ├─ tag            "dialog", "confirm", ... — чтобы спросить modalIsOpen("dialog")
    ├─ рамка          layout, widthFrac, heightFrac, padding, background, dim
    ├─ поведение      navAxis, canCancel, inputGuard, charsPerStep
    ├─ хуки           onOpen, onClose, onCancel, drawUnderPanel, drawOverPanel
    └─ pages[]        страницы по очереди (реплики диалога, шаги обучения)
        └─ page
           ├─ blocks[]      что нарисовать, сверху вниз
           ├─ onEnter       при входе на страницу
           ├─ advanceWhen   своё условие «дальше» (обучение)
           ├─ spotlight     что подсветить (обучение)
           └─ любое поле окна, чтобы переопределить его для этой страницы

    block
    ├─ kind     "title", "text", "buttons", "card", "row", ...
    ├─ h / w    доля высоты (в колонке) или ширины (в ряду), "fill" или "square"
    └─ свои параметры (text, color, items, ...)

Как идёт окно:
  - открылось -> страница 0;
  - на странице есть выбираемые элементы (кнопки, ответы, карты) -> курсор,
    подтверждение вызывает item.onSelect;
  - элементов нет -> подтверждение/клик листает страницы, после последней окно
    закрывается;
  - печать по буквам: первое нажатие допечатывает текст, второе листает;
  - отмена (ПКМ, Esc, C) — только если canCancel.

Раскладка блоков: страница — это колонка. Блоки с числом h получают долю
высоты, блоки "fill" делят остаток поровну. Ряд (ModalRow) делает то же по
ширине. Ряды и колонки вкладываются друг в друга — так собираются «портрет
слева, текст справа» и «картинка врага + статистика».

  ЧАСТЬ 3. ЯДРО: scrModal
================================================================================

Три новых скрипта и один объект создавай В IDE GameMaker (правой кнопкой ->
Create), а потом вставляй код. Если создавать файлы снаружи, их нужно руками

3.1. Начало скрипта: перечисления, глубина, слияние структур

    #macro MODAL_DEPTH -15000

    enum ModalLayout { Center, Bottom, Top, FullScreen }

    function modalMerge(target, source) {
        var names = variable_struct_get_names(source)
        for (var nameIndex = 0; nameIndex < array_length(names); nameIndex++) {
            target[$ names[nameIndex]] = source[$ names[nameIndex]]
        }
        return target
    }

  MODAL_DEPTH ниже паузы (-10000) — окна всегда поверх интерфейса боя и меню.
  Это та же глубина, что была у oCardReward.

3.2. Окно с умолчаниями

    function modalSpec(overrides = {}) {
        var spec = {
            tag: "",
            layout: ModalLayout.Center,
            widthFrac: 0.5,
            heightFrac: 0.34,
            padding: 0.12,
            paddingXScale: 1,
            blockGap: 0.03,
            dim: 0.6,
            background: box,
            spotlight: undefined,
            navAxis: "horizontal",
            charsPerStep: 0.8,
            inputGuard: 1,
            canCancel: false,
            pages: [],
            drawUnderPanel: undefined,
            drawOverPanel: undefined,
            advanceWhen: undefined,
            onOpen: undefined,
            onClose: undefined,
            onCancel: undefined
        }
        return modalMerge(spec, overrides)
    }

  Что значат поля:
    widthFrac, heightFrac — размер рамки в долях экрана GUI;
    padding               — отступ внутри рамки, доля её высоты;
    paddingXScale         — во сколько раз боковой отступ больше (у диалога 1.5);
    blockGap              — зазор между блоками, доля высоты рамки;
    dim                   — затемнение экрана, 0 — без затемнения;
    background            — спрайт рамки, undefined — без рамки;
    inputGuard            — сколько кадров после открытия игнорировать ввод;
    navAxis               — "horizontal" (A/D, стрелки влево-вправо)
                            или "vertical" (W/S).

3.3. Открыть, проверить, закрыть

    function modalOpen(spec, overrides = undefined) {
        if (!variable_global_exists("modalBlocks")) { modalBlocksInit() }
        if (overrides != undefined) { modalMerge(spec, overrides) }
        if (!instance_exists(oModal)) { instance_create_depth(0, 0, MODAL_DEPTH, oModal) }
        var modalWindow = new ModalWindow(spec)
        with (oModal) { pushWindow(modalWindow) }
        return modalWindow
    }

    function modalIsOpen(tag = undefined) {
        if (!instance_exists(oModal)) { return false }
        return oModal.hasWindow(tag)
    }

    function modalClose(tag = undefined) {
        if (!instance_exists(oModal)) { return }
        with (oModal) {
            for (var windowIndex = 0; windowIndex < array_length(windows); windowIndex++) {
                if (tag == undefined || windows[windowIndex].spec.tag == tag) { windows[windowIndex].close() }
            }
        }
    }

  Реестр блоков создаётся при первом открытии окна, как uiFontInit в
  fitWrappedText. Отдельно вызывать его в oGameController не нужно.
  Локальная переменная modalWindow видна внутри with — это нормально для GML.

3.4. Само окно

    function ModalWindow(spec) constructor {
        self.spec = spec
        if (array_length(self.spec.pages) == 0) { self.spec.pages = [{ blocks: [] }] }
        self.pageIndex = 0
        self.charProgress = 0
        self.cursor = 0
        self.items = []
        self.itemRects = []
        self.inputGuard = spec.inputGuard
        self.closed = false
        self.age = 0
        self.panel = { x: 0, y: 0, w: 0, h: 0 }

        self.page = function() { return self.spec.pages[self.pageIndex] }

        self.option = function(name) {
            var current = self.page()
            return variable_struct_exists(current, name) ? current[$ name] : self.spec[$ name]
        }

        self.enterPage = function(index) {
            self.pageIndex = index
            self.charProgress = 0
            self.cursor = 0
            self.itemRects = []
            var current = self.page()
            self.items = modalCollectItems(current.blocks, [])
            var onEnter = current[$ "onEnter"]
            if (onEnter != undefined) { onEnter(self) }
        }

        self.revealLength = function() { return modalRevealLength(self.page().blocks) }
        self.fullyRevealed = function() { return floor(self.charProgress) >= self.revealLength() }
        self.revealAll = function() { self.charProgress = self.revealLength() }

        self.next = function() {
            if (self.pageIndex + 1 >= array_length(self.spec.pages)) {
                self.close()
                return
            }
            self.enterPage(self.pageIndex + 1)
        }

        self.close = function() {
            if (self.closed) { return }
            self.closed = true
            if (self.spec.onClose != undefined) { self.spec.onClose(self) }
        }

        self.cancel = function() {
            self.close()
            if (self.spec.onCancel != undefined) { self.spec.onCancel(self) }
        }

        self.select = function(itemIndex) {
            var item = self.items[itemIndex]
            if (item[$ "closes"] ?? true) { self.close() }
            if (item[$ "onSelect"] != undefined) { item.onSelect(self, item) }
        }

        self.addItemRect = function(item, rectX, rectY, rectW, rectH) {
            array_push(self.itemRects, { x: rectX, y: rectY, w: rectW, h: rectH, index: item.index })
        }

        self.step = function(input) {
            if (self.closed) { return }
            self.age++
            if (!self.fullyRevealed()) { self.charProgress += self.option("charsPerStep") }
            if (self.inputGuard > 0) {
                self.inputGuard--
                return
            }
            if (input.cancel && self.option("canCancel")) {
                self.cancel()
                return
            }
            var advanceWhen = self.option("advanceWhen")
            if (advanceWhen != undefined) {
                if (advanceWhen(self)) { self.next() }
                return
            }
            if (!self.fullyRevealed()) {
                if (input.confirm || input.clicked) { self.revealAll() }
                return
            }
            if (array_length(self.items) == 0) {
                if (input.confirm || input.clicked) { self.next() }
                return
            }
            self.stepCursor(input)
        }

        self.stepCursor = function(input) {
            var count = array_length(self.items)
            var vertical = (self.option("navAxis") == "vertical")
            if (vertical ? input.up : input.left) { self.cursor = (self.cursor - 1 + count) mod count }
            if (vertical ? input.down : input.right) { self.cursor = (self.cursor + 1) mod count }
            var confirm = input.confirm
            for (var rectIndex = 0; rectIndex < array_length(self.itemRects); rectIndex++) {
                var itemRect = self.itemRects[rectIndex]
                if (pointInRect(input.guiX, input.guiY, itemRect.x, itemRect.y, itemRect.w, itemRect.h)) {
                    if (input.moved || input.clicked) { self.cursor = itemRect.index }
                    if (input.clicked) { confirm = true }
                    break
                }
            }
            if (confirm) { self.select(self.cursor) }
        }

        self.draw = function() {
            var spotlight = self.option("spotlight")
            var focusRect = (spotlight != undefined) ? spotlight() : undefined
            if (focusRect != undefined) { drawTutorialSpotlight(focusRect) }
            else if (self.option("dim") > 0) { drawScreenDim(self.option("dim")) }

            self.panel = modalPanelRect(self, focusRect)
            var drawUnder = self.option("drawUnderPanel")
            if (drawUnder != undefined) { drawUnder(self, self.panel) }
            var background = self.option("background")
            if (background != undefined) {
                draw_sprite_stretched(background, 0, self.panel.x, self.panel.y, self.panel.w, self.panel.h)
            }

            var padY = self.panel.h * self.option("padding")
            var padX = padY * self.option("paddingXScale")
            self.itemRects = []
            modalLayoutBlocks(self, self.page().blocks, {
                x: self.panel.x + padX,
                y: self.panel.y + padY,
                w: self.panel.w - padX * 2,
                h: self.panel.h - padY * 2
            }, false)

            var drawOver = self.option("drawOverPanel")
            if (drawOver != undefined) { drawOver(self, self.panel) }
            draw_set_halign(fa_left)
            draw_set_valign(fa_top)
            draw_set_color(c_white)
            draw_set_alpha(1)
        }
    }

  Порядок в select такой же, как был в oDialogManager: сначала окно
  закрывается (onClose = «диалог закончен»), потом вызывается колбэк ответа.
  Если колбэк откроет новое окно (квест -> «Новая карта»), оно встанет в стек
  уже после закрытия старого.
  item.closes = false — кнопка, которая НЕ закрывает окно (например, «ещё»).
  itemRects собираются при отрисовке и используются в следующем Step — так же,
  как runConfirmHitRects и gameOverHitRects сейчас.

3.5. Рамка: где стоит окно

    function modalPanelRect(modalWindow, avoidRect) {
        var screenWidth = display_get_gui_width()
        var screenHeight = display_get_gui_height()
        var panelW = screenWidth * modalWindow.option("widthFrac")
        var panelH = screenHeight * modalWindow.option("heightFrac")
        switch (modalWindow.option("layout")) {
            case ModalLayout.Bottom:
                return { x: (screenWidth - panelW) * 0.5, y: screenHeight - panelH - round(screenWidth * 0.02), w: panelW, h: panelH }
            case ModalLayout.Top:
                return modalTopAvoiding(panelW, panelH, avoidRect)
            case ModalLayout.FullScreen:
                return { x: 0, y: 0, w: screenWidth, h: screenHeight }
            default:
                return { x: (screenWidth - panelW) * 0.5, y: (screenHeight - panelH) * 0.5, w: panelW, h: panelH }
        }
    }

    function modalRectsOverlapY(panel, rect) {
        return (panel.y < rect.y + rect.h) && (panel.y + panel.h > rect.y)
    }

    function modalTopAvoiding(panelW, panelH, avoidRect) {
        var screenWidth = display_get_gui_width()
        var screenHeight = display_get_gui_height()
        var margin = (screenWidth - panelW) * 0.5
        var panel = { x: margin, y: screenHeight * 0.03, w: panelW, h: panelH }
        if (avoidRect == undefined || !modalRectsOverlapY(panel, avoidRect)) { return panel }
        panel.y = screenHeight - screenHeight * 0.03 - panelH
        if (!modalRectsOverlapY(panel, avoidRect)) { return panel }
        var gapLeft = avoidRect.x
        var gapRight = screenWidth - (avoidRect.x + avoidRect.w)
        var onRight = (gapRight >= gapLeft)
        var sideGap = onRight ? gapRight : gapLeft
        panel.h = screenHeight * 0.32
        panel.y = (screenHeight - panel.h) * 0.5
        panel.w = clamp(sideGap - margin * 1.2, screenWidth * 0.22, screenWidth * 0.46)
        panel.x = onRight ? (avoidRect.x + avoidRect.w) + (sideGap - panel.w) * 0.5 : (sideGap - panel.w) * 0.5
        return panel
    }

  modalTopAvoiding — это логика из drawTutorialPanel без изменений: рамка
  сверху; закрывает подсветку — вниз; снизу тоже — сбоку, где больше места.

3.6. Раскладка блоков

    function modalBlockLength(size, total, cross, fillSize) {
        if (is_string(size)) { return (size == "square") ? cross : fillSize }
        return total * size
    }

    function modalLayoutBlocks(modalWindow, blocks, area, horizontal) {
        var count = array_length(blocks)
        if (count == 0) { return }
        var total = horizontal ? area.w : area.h
        var cross = horizontal ? area.h : area.w
        var gap = modalWindow.panel.h * modalWindow.option("blockGap")
        var fixedSize = 0
        var fillCount = 0
        for (var blockIndex = 0; blockIndex < count; blockIndex++) {
            var size = horizontal ? blocks[blockIndex].w : blocks[blockIndex].h
            if (is_string(size) && size == "fill") { fillCount++ }
            else { fixedSize += modalBlockLength(size, total, cross, 0) }
        }
        var fillSize = max(0, (total - fixedSize - gap * (count - 1)) / max(1, fillCount))
        var offset = 0
        for (var blockIndex = 0; blockIndex < count; blockIndex++) {
            var block = blocks[blockIndex]
            var length = modalBlockLength(horizontal ? block.w : block.h, total, cross, fillSize)
            var rect = horizontal
                ? { x: area.x + offset, y: area.y, w: length, h: area.h }
                : { x: area.x, y: area.y + offset, w: area.w, h: length }
            modalDrawBlock(modalWindow, block, rect)
            offset += length + gap
        }
    }

    function modalDrawBlock(modalWindow, block, rect) {
        var handler = global.modalBlocks[$ block.kind]
        if (handler == undefined) {
            show_debug_message("modal: unknown block " + string(block.kind))
            return
        }
        handler.draw(block, modalWindow, rect)
        draw_set_halign(fa_left)
        draw_set_valign(fa_top)
        draw_set_color(c_white)
        draw_set_alpha(1)
    }

  Сравнение size == "fill" только после is_string: сравнивать число со строкой
  в GML — путь к ошибке.
  После каждого блока выравнивание и цвет сбрасываются — блок не может
  «испортить» соседа.

3.7. Обход дерева блоков: элементы и длина печати

    function modalCollectItems(blocks, items) {
        for (var blockIndex = 0; blockIndex < array_length(blocks); blockIndex++) {
            var block = blocks[blockIndex]
            if (variable_struct_exists(block, "children")) { modalCollectItems(block.children, items) }
            if (variable_struct_exists(block, "items")) {
                for (var itemIndex = 0; itemIndex < array_length(block.items); itemIndex++) {
                    var item = block.items[itemIndex]
                    item.index = array_length(items)
                    array_push(items, item)
                }
            }
        }
        return items
    }

    function modalRevealLength(blocks) {
        var longest = 0
        for (var blockIndex = 0; blockIndex < array_length(blocks); blockIndex++) {
            var block = blocks[blockIndex]
            if (variable_struct_exists(block, "children")) { longest = max(longest, modalRevealLength(block.children)) }
            if (block.kind == "text" && block.typewriter) {
                longest = max(longest, block[$ "revealLength"] ?? string_length(block.text))
            }
        }
        return longest
    }

  Все выбираемые элементы страницы (кнопки, ответы, карты) — в одном массиве

  revealLength блок text записывает при отрисовке (подобранный текст с
  переносами чуть длиннее исходного).

================================================================================
  ЧАСТЬ 7. ЛОВУШКА GML: ФУНКЦИИ НЕ ЗАХВАТЫВАЮТ ЛОКАЛЬНЫЕ ПЕРЕМЕННЫЕ
================================================================================

В JavaScript так работает:

    var card = cards[i]
    onSelect: function() { onPick(card) }

В GML — нет. Анонимная функция не видит var-переменные того места, где её
создали. Внутри неё card и onPick будут искаться как поля self, и в лучшем
случае будет ошибка, в худшем — молча возьмётся чужое значение.

Три рабочих способа, все уже используются в проекте или в гайде:

  1) Привязать к экземпляру: method(self, function() { ... }).
     Внутри видны поля объекта (Battle). Так написаны все хуки состояний боя.

         var backToPlay = method(self, function() { changeBattleState(BattleStates.CharacterPlay) })

  2) Привязать к структуре с данными: method({ ... }, function() { ... }).
     Нужные значения кладутся в структуру, функция видит их как поля self.

         onSelect: method({ card: card, onPick: onPick }, function() { onPick(card) })

  3) Передать функцию как есть, без обёртки, если она уже готова:
     onClose: onComplete. Метод помнит, к чему он привязан, куда бы его ни
     положили.

Правило для кнопок окна: колбэк создавай в локальную переменную ДО литерала
структуры через method(...), а в литерал клади уже переменную. Тогда не надо
разбираться, к чему GML привяжет функцию, объявленную внутри { }.

9.4. Своя страница внутри обычного диалога
  extraBlocks из 6.2: например, сундук с картой показывает саму карту.
  oChest, ChestKind.Card, было:

    say([ dialogLine("Chest", noone, loc("chest.cardPre") + cardName + loc("chest.cardPost")) ])

  стало:

    var chestLine = dialogLine("Chest", noone, loc("chest.cardPre") + cardName + loc("chest.cardPost"))
    chestLine.extraBlocks = [ModalCard(card, { h: 0.6 })]
    chestLine.pageOverrides = { heightFrac: 0.6, layout: ModalLayout.Center }
    say([chestLine])

  Высоты рамки диалога (0.30 экрана) на карту мало, поэтому эта страница
  переопределяет высоту и положение рамки. Работает, потому что окно ищет
  любое поле сначала в странице, потом в окне (option()). Остальные реплики
  того же диалога остаются обычными.

9.5. Окно, которое закрывается само («тост»)

    modalOpen(modalSpec({
        tag: "toast",
        layout: ModalLayout.Top,

        heightFrac: 0.08,
        dim: 0,
        advanceWhen: function(modalWindow) { return modalWindow.age > game_get_speed(gamespeed_fps) * 2 },
        pages: [{ blocks: [ModalTitle(loc("ui.saved"))] }]

  тостов, которые не должны мешать, добавь в spec поле blocksInput: false и
  учитывай его в pushWindow / Begin Step (не трогать uiModal) и в Step
  менеджера (ввод получает верхнее окно, у которого blocksInput = true).

9.6. Анимация появления
  У окна есть age (кадры с открытия). В ModalWindow.draw после
  self.panel = modalPanelRect(...):

            var openFrames = self.option("openFrames") ?? 0
            if (openFrames > 0 && self.age < openFrames) {
                var growth = 0.85 + 0.15 * (self.age / openFrames)
                var centerX = self.panel.x + self.panel.w * 0.5
                var centerY = self.panel.y + self.panel.h * 0.5
                self.panel.w *= growth
                self.panel.h *= growth
                self.panel.x = centerX - self.panel.w * 0.5
                self.panel.y = centerY - self.panel.h * 0.5
            }

  и openFrames: 0 в modalSpec. Включается в любом пресете: { openFrames: 8 }.

  onOpen / onClose в spec. Если звук нужен ВСЕМ окнам — в pushWindow и
  removeClosed менеджера, а не в каждом пресете.

Частые ошибки:
  * Колбэк кнопки ссылается на локальную переменную (card, onPick) — в GML
    её там нет. Часть 7: method(self, ...) или method({ данные }, ...).
  * size == "fill" без is_string — ошибка сравнения числа со строкой.
  * Забыт общий стоп в Battle Step (8.3): ПКМ закрывает окно и одновременно
    срабатывает OnCancel состояния — бой уходит не туда.
  * global.uiModal = false сразу при закрытии (а не в Begin Step) —
    сквозной клик: закрыл диалог Enter'ом, и тот же Enter открыл сундук.

    объекта — а GML привязал её к самой структуре. Создавай колбэк в
    переменную до литерала.

    cardDetails падает.
  * Удалён drawTutorialSpotlight вместе с TutorialRunner — обучение падает.
